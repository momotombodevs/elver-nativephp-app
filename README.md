# Elver

Aplicación climática local-first construida con Laravel, NativePHP Mobile y nativephp-charts.

## Incluye

- Resumen climático y explorador de series nativas.
- Ubicaciones y alertas almacenadas en SQLite.
- Pronósticos de Open-Meteo con caché offline.
- Plugin local de geolocalización para iOS y Android.
